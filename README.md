# 電影探索應用

一個使用React開發的電影探索應用，串接TMDB API顯示真實電影資料，主要參考威秀官網設計。

## 功能
- 首頁輪播Banner
- 顯示四大分類：熱門電影、正在上映、即將上映、高評分
- 即時搜尋電影(含debounce防抖優化)
- 搜尋 empty state / error state / loading state 處理
- 訂票表單功能
- 最新公告列表
- 導覽列(首頁和訂票頁面各自不同)

## 使用技術

- React
- React Router
- Vite
- TMDB API
- CSS
